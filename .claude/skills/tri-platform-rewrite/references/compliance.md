# 合规红线清单

> 写作**之前**过一遍，不是写完再查。三平台（尤其头条、百家号）对以下类目的处罚是账号级的，不是单篇级的。

> 极限词／标题党词／「第一是」误判坑／加粗配额，见 `extreme-words.md`。


---

## 一、必须整条删除（不写、不改写、不模糊化）

### 1. 教唆规避平台风控 / 违反服务条款

技术社区材料里常年出现这类内容，**在任何公开平台传播都属于高危**：

- 「过风控」「降低封号率」「账号池」「指纹浏览器」
- 「订阅反代」「sub2api」「一个订阅多人共用」「代理转发」
- 「改时区绕过环境检测」「伪装客户端」「伪装设备」
- 「KYC 绕过」「虚拟卡开号」「批量注册」
- 破解、去授权、盗版资源获取路径

即使原文只是"技术分享"，改写后发到公开平台，性质就是**提供规避手段**。一律删。

### 2. 已证伪信息

原文自己标注了"不实信息""已辟谣"的，**整条不写**。不要在文章里写"曾传出……后被证伪"——证伪信息本身也会被二次传播。

### 3. 无信源的具体数字

- 只有推文/爆料来源的价格、营收、融资额 → 只能写"传闻"，且**不给具体数字**
- 「据说」「网传」「内部人士」开头的关键数据 → 不给数
- 例外：数字本身是新闻事件（如"半小时卖10万份"已有媒体报道），可写并加"据报道"

### 4. 外链与导流

- 百家号：**禁止一切 `http://` `https://`**（含模型 API 地址、GitHub 仓库、HuggingFace）
- 头条：正文外链会限流
- 公众号：只能引用公众号文章链接
- 二维码、微信号、QQ 群、邮箱一律不写

## 二、必须改写或加限定

| 类型 | 处理方式 |
|---|---|
| 金融荐股 | 「关注XX板块」「利好XX」「可以买入」→ 全删。产业链分析可以写，涉及个股一律不点名 |
| 医疗断言 | 「包治」「根治」「替代药物」→ 改成「有助于」「部分人反馈」。健康类文末加「具体请遵医嘱」 |
| 法律结论 | 不写「这构成违法」，改写「法院认定/据报道，法院认为……」 |
| 商业诋毁 | 对具体公司的负面，必须是可查证的公开事实（财报、判决、官方声明），并附来源；主观评价用「有用户认为」 |
| 群体对立 | 不写男女对立、地域对立、城乡对立、阶层对立的煽动表达 |
| 未成年人 | 涉未成年人不写姓名、学校、住址、照片 |
| 普通人隐私 | 一律脱敏：李先生、王女士、某公司员工 |

## 三、标题与开头

**禁止**：震惊、速看、删前速看、不看后悔、99%的人不知道、紧急通知、刚刚、重磅（堆砌时）

**允许的强度**：数字、反问、反差、具体事件、明确结论

判断标准：**标题承诺的内容，正文前三分之一必须兑现。** 兑现不了就是标题党。

---

## 四、AI 声明

三平台都在收紧 AI 内容治理：

- 头条有「引用 AI」勾选项
- 百家号有「引用 AI」勾选项
- 公众号暂无强制项，但流量主审核会看

**建议做法**：AI 参与写作（哪怕只是改写）就勾选。勾了会略降推荐权重，但不勾被识别后处罚更重（限流、取消原创、扣信用分）。

在发布说明里明确写给用户，不要替他决定。

---

## 五、搬运判定

平台判「全网搬运」不只看文字重复率，还看：

1. 三平台标题是否一致
2. 开头第一段是否一致
3. 小标题是否一字不差
4. 段落顺序是否完全对应
5. 结尾互动句是否相同

**规避方法**：三份稿件的开头、小标题、结尾、段落顺序必须实质不同。同一段文字最多在一份里出现。

---

## 六、交付时必须写进「发布说明」的三件事

1. **删了什么、为什么删**（列清单，让用户知道原文有多长被砍掉了）
2. **哪些数字属社区转述，需用户自行核验**（列出数字清单）
3. **哪些地方做了模糊化处理**（如把「Anthropic」改成「一家头部AI公司」），并说明可以改回来

---

## 七、事实取证：别把转载当证据

日报类材料最常见的坑，是把"三家媒体都报了"当成"三个独立信源"。**实际可能全是同一篇通稿的转载。**

**取证规则：**

1. **至少为核心事实找到一个权威原始来源**（公告、财报、监管文件、法院判决、官方账号原文）
2. **多个转载 ≠ 独立证据**。要找"最早发出的那一个"，而不是数转载数量
3. 找不到原始来源时，**如实标注为二手报道，并降低结论强度**（把"就是"改成"据报道"）
4. 重要争议要列分歧，不能只写一方
5. 整理一张内部清单：`事实 — 来源 — 日期 — 可用表述`，再动笔写涉及人名、机构、规则、价格、指标的句子

**发布版与核对版分开：**

- 核对阶段：每个数字都标源（内部用）
- 发布阶段：**删掉正文里的"（数据：XX）""来源：XX"括号标注，只留数字本身**

爆款文里挂来源括号，读起来像论文脚注，读者出戏。但**去掉的是标注，不是数据——数字一个都不能动**。

---

## 八、纯净正文交付

可发布区域从主标题开始、到正文结束，中间**不插入**：

- "来源：XX""参考资料""数据来自 XX"标签
- 可点击的引用卡片、来源网址、脚注编号
- "下面是可直接复制的版本"这类助手提示语
- 内部打分、核查过程、创作说明

这些内容放在 `发布说明.md` 里，不放进正文。自然语言归属（"马斯克在 X 上表示""招股书披露"）是内容的一部分，要保留——它不是引用卡片。
