# 三平台规格与受众对照

> 数据为创作者实践与公开行业观察的汇总，平台规则会变，**关键条款以各平台创作者后台的实际提示为准**。

---

## 一、硬规格速查

| 项目 | 微信公众号 | 今日头条 | 百家号 |
|---|---|---|---|
| 标题字数 | ≤64 字（建议 18-26） | 建议 20-28 字（上限 30） | ≤40 字（建议 22-30） |
| 摘要 | 有，≤120 字 | 无（用开头第一段当摘要） | 部分版本有摘要栏，≤100 字 |
| 正文字数 | 1500-4000（2500-3500 最佳） | 800-2000（1200-1800 最佳） | 800-2000（1500-2200 最佳） |
| 段落长度 | 3-5 行 | **1-3 行**（手机屏 2 屏/段最差） | 2-4 行 |
| 图片 | 需先上传图床，正文内最多 20 张 | 单图/三图，封面 16:9 | 单图/三图，封面 16:9 |
| 外链 | 仅可引用公众号文章 | 正文外链会限流 | **禁止一切外链** |
| 二维码/联系方式 | 禁止（导流违规） | 禁止 | 禁止 |
| 富文本 | 支持内联样式 HTML | 仅基础加粗/居中 | 仅基础加粗/居中 |
| 必填项 | 标题、正文、封面 | 标题、正文、领域、封面 | 标题、正文、分类、标签、封面 |
| 原创声明 | 默认（原创标） | 可选「原创」，影响单价 | 「原创」必勾（影响推荐与维权） |
| AI 声明 | 无强制 | 有「引用 AI」勾选项 | 有「引用 AI」勾选项 |

**格式陷阱**：
- 头条/百家号编辑器**不解析 Markdown**，`**加粗**` 会原样显示成星号
- 公众号编辑器**会过滤 `<style>` 标签**，只能用 inline style；flex/grid 在部分客户端失效
- 百家号正文里出现 `http://` `https://` 可能直接审核不通过

## 二、受众画像

### 今日头条

| 维度 | 特征 |
|---|---|
| 年龄 | 核心 30-55 岁；45 岁以上占比高且**日均时长最长（50-70 分钟）**；银发族增长最快 |
| 地域 | 约七成在三四线及以下城市、县城乡镇 |
| 性别 | 男性略多（约 55:45） |
| 学历 | 高中至大专为主，本科及以上约两成 |
| 阅读方式 | 算法被动推荐，不主动搜索；早通勤、午休、**晚 20:00-23:00** 三高峰 |
| 爱看什么 | 民生政策（社保医保养老金）、健康养生、情感家长里短、实用干货、赚钱副业、历史军事、本地资讯、社会热点、怀旧 |
| 不爱看什么 | 长术语、纯技术细节、需要前置知识的分析、说教 |

**写作含义**：头条读者不认作者，只认"这条跟我有没有关系"。标题里要有数字、有冲突、有"我们/普通人/影响/意味着"。开头三行决定生死。

### 百家号

| 维度 | 特征 |
|---|---|
| 年龄 | 25-45 为主，比头条年轻一档 |
| 地域 | 一二线与三四线混合，一线占比高于头条 |
| 阅读来源 | **搜索占比显著高于头条**，百度搜索长尾是主要增量 |
| 爱看什么 | 资讯解读、财经产业、科技数码、职场、生活科普、教育 |
| 内容偏好 | 接受小标题、接受数据、接受"三个信号/四个变化"这类结构化表达 |

**写作含义**：百家号要**给搜索引擎留钩子**——小标题里带关键词、正文里把"是什么/为什么/意味着什么"讲全。同一篇在头条要短，在百家号可以更"信息完整"。

### 微信公众号

| 维度 | 特征 |
|---|---|
| 年龄 | 25-40 为主，一二线为主 |
| 阅读来源 | 订阅关系 + 转发，**打开率取决于标题和人设信任** |
| 爱看什么 | 有观点、有信息增量、有作者立场的长文；能"看完有收获"的内容 |
| 内容偏好 | 容忍长文，接受术语，接受复杂结构，反感注水 |

**写作含义**：公众号是唯一可以"多线并行"的平台。可以在一篇里讲四五件事，只要有一条主线把它们串起来。人设（🐒、老X、某某君）是资产，要保留。

## 三、收益机制（用于给用户建议，不要写进正文）

| 平台 | 主要收益 | 关键系数 |
|---|---|---|
| 头条 | 广告分成（图文 / 微头条 / 视频 / 问答）+ 首发补贴 + 征文 + 带货 + 专栏 | 千次获利阅读单价 × 互动系数(1-3) × 获利阅读量 ÷1000 + 补贴 |
| 百家号 | 广告分成 + 原创补贴 + 活动 + 带货 | 单价与原创标、领域垂直度、完读率强相关 |
| 公众号 | 流量主广告 + 赞赏 + 互选广告 + 付费阅读 + 私域转化 | 无统一单价，靠粉丝量与打开率 |

**头条「获利阅读」判定**：用户停留 ≥30 秒、页面滚动 ≥70%、且广告曝光才计费。划走、秒退、机刷不计。

**头条「首发」**：勾选原创+首发且 72 小时内全网未发，可拿 1.5-3 倍分成（有单篇上限）。这是三平台分发时最大的冲突点。

## 四、发布时间

| 平台 | 首选 | 次选 | 说明 |
|---|---|---|---|
| 公众号 | 20:30-21:30 | 07:30-08:30 | 订阅号晚间打开率峰值 |
| 头条 | 18:00-19:00 | 21:00-22:00 | 图文晚高峰；社会/财经话题晚发更好 |
| 百家号 | 08:00-09:00 | 12:00-13:00 | 早间资讯流，且与头条错开小时 |

三平台同一天发时，**至少错开 2 小时**，避免同时段自我竞争推荐位。

## 五、标题公式（按平台）

**头条**（要数字 + 冲突 + 悬念，不要形容词堆砌）
- `[具体数字/事件]，[反转或代价]` → 李佳琦半小时卖出2万亿Token，马斯克却说这生意撑不住了
- `[大家都在夸的事]，[但是]` → 都在说AI免费了，但马斯克说了句实话

**百家号**（要关键词 + 结论，利于搜索）
- `[概念]正在[变化]：[事件]背后的[N]个信号`
- `从[具体事件]说起：[行业判断]`

**公众号**（可以更情绪化、更文学，靠人设背书）
- 短句、断言、留白：`AI的免费午餐，正在收摊`
- 疑问句制造好奇：`我们是不是正在告别免费的AI？`

**三平台标题必须不同。** 同一个标题全网铺，是最容易被判搬运的信号之一。

## 六、头条流量池：选题决定天花板

头条是**分层流量池**机制，不是发出去就全国推：

冷启动（0-2h）→ 初级池（约 5千-2万展现）→ 中级池（3万-10万）→ 高级池（15万-50万+）

每级晋级看三项：**点击率 CTR、完读率、互动率**。关键阈值（实践值，非官方）：
- CTR 健康线约 8%，**低于 3% 基本卡在初级池**
- 完读率**低于 30-35% 系统不再放量**（这是最大瓶颈）
- 评论区互动（评论 > 转发 > 点赞）撬动二次推荐

**三条推导，直接决定改写策略：**

| 决定项 | 结论 |
|---|---|
| **展现天花板 = 选题是否带全民热词** | 带"苹果/华为/芯片/GPT/房价/存款利率/黄金"这类词的题，能跨圈拿展现；纯垂类深度题（电池/创新药/航运）即便写得好，也容易被锁在 2000 量级。**账号没死，是选题卡住了池子。** |
| **CTR = 标题冲突度 + 封面** | 标题要把冲突或数字怼到脸前；封面**三图 > 单图 > 无图**，数据对比图对 CTR 拉动最直接 |
| **完读率 = 内容形态** | 短段落 + 硬数据 + 对比结构，完读率远高于纯论述 |

**两个操作禁忌：**
- **发布后 2 小时内改标题会清空已积累流量**，等于重发。想改就等凉了再改。
- 被驳回要按后台提示针对性修改，**不要原样重复提交**，会伤账号权重。

**数据诊断口诀**（用户拿到后台数据时用）：
- CTR < 3% → 先查账号权重 / 封面 / 流量池，再谈内容
- CTR 正常但完读低 → 纯内容病（开头 / 节奏 / 长度）
- 完读正常但展现低 → 选题缺全民热词

**改写时的直接应用**：从日报里选主线时，优先选**能自然带上全民热词**的那条。本次案例中"AI 订阅涨价 / Token / 马斯克"都是全民词，而"MoE 专家数 / 张量并行"不是。

## 七、前 150 字生死线

头条和百家号都在手机上被"单手划屏"消费，**前 150 字没有反转、冲突、悬念或具体的人，后面写多好都没人看**。

**禁止用新闻导语开头**：
- ❌ "11月2日，某公司宣布……"（这是通知，不是钩子）
- ❌ "近日，一则消息引发关注"（零信息）

**四种可用开头**：
1. 全网都在说 X，其实是 Y
2. 一个具体的人 + 具体时间 + 具体的事
3. 一句被读反的话
4. 一个反常识的数据

公众号不适用这条——订阅读者已经给你注意力了，可以从人设或观点起。
